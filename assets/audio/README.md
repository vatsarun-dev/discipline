Place predefined AI voice reminder MP3 files here.

Required folders:
- first-reminder/1.mp3 through first-reminder/8.mp3
- second-reminder/1.mp3 through second-reminder/8.mp3
- final-reminder/1.mp3 through final-reminder/8.mp3

The backend selects a random available MP3 for the reminder stage and avoids immediately repeating the last played file.
